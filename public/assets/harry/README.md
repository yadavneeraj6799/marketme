- harry-idle.webp

- harry-point-right.webp
- harry-point-left.webp
- harry-present.webp
- harry-thinking.webp
- harry-analyse.webp
- harry-idea.webp
- harry-celebrate.webp
- harry-walk.webp
- harry-cta.webp

The `HarryMascot` component checks for these images automatically and seamlessly replaces the built-in vector illustration whenever they are placed in this folder.
